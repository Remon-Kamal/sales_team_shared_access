
# Sales Team Shared Access

Odoo 16 module that allows sales users to access quotations and sales orders of their own sales team only.

## Features

- Team-based quotation visibility
- Restrict access to other teams
- Easy security configuration
- Compatible with Odoo 16 Community

## Installation

1. Copy module to custom addons folder
2. Update Apps List
3. Install the module

## Dependencies

- sale
- crm
